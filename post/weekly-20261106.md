This week we cover zero-knowledge proofs for LLM inference, a Lean-certified STARK verifier in OpenVM, and Ethereum block-proving benchmarks from Pico and Ziren. The papers explore bit packing and ring switching over binary fields, threshold anonymous credentials, and the conditions for preserving Fiat–Shamir extraction when instantiating the random oracle.

## Papers

### Sumcheck bit packing
- Matteo Frigo, abhi shelat
- Uses the field trace to check linear claims about witness bits packed into binary extension-field elements.
- <https://eprint.iacr.org/2026/2770>

### AirBB: Lightweight Threshold Anonymous Credentials without Random Oracles from BB Signatures
- Sebastian Faust, Jonas Hofmann, Philipp-Florens Lehwalder, Hussien Othmann
- Builds threshold anonymous credentials from Boneh–Boyen signatures without random oracles.
- <https://eprint.iacr.org/2026/2762>

### A note on zero-knowledge ring switching
- Andrei Kochergin
- Gives a zero-knowledge version of Diamond and Posen's ring-switching technique.
- <https://eprint.iacr.org/2026/2754>

### Beyond Standard Indifferentiability: Simulator Properties for Fiat-Shamir Security
- Ashrujit Ghoshal, Sikhar Patranabis
- Studies when Fiat–Shamir knowledge extraction is preserved as a structured hash replaces the random oracle.
- <https://eprint.iacr.org/2026/2708>

### Nenya: Efficient zkSNARKs for Integer Rings Z/2kZ via Reverse Multiplication-Friendly Embeddings
- Tianyu Zhang, Nikita Borisov, Yupeng Zhang
- A zkSNARK for native fixed-width integer arithmetic using reverse multiplication-friendly embeddings.
- <https://eprint.iacr.org/2026/2672>

### Improving Code Rate and Query Complexity for the Ligero-IOP System
- Ignacio Cascudo, Carmit Hazay, Muthu Venkitasubramaniam
- Sharpens Ligero's soundness analysis and introduces a variant that supports higher Reed–Solomon code rates.
- <https://eprint.iacr.org/2026/2681>

### Weir: Bounded-Memory Indexing and Proving with Sequential Storage
- Kyeongtae Lee, Jihye Kim, Hyunok Oh
- A Shockwave-based prover that uses sequential storage to keep RAM usage low during indexing and proving.
- <https://eprint.iacr.org/2026/2689>

### Anamorphic Proofs of Knowledge from Prover Randomness
- Zhi Lu, Songfeng Lu, Jiaheng Zhang
- Uses prover randomness to let a public proof also certify knowledge of a hidden witness to a designated verifier.
- <https://eprint.iacr.org/2026/2706>

### Authenticated Outsourced Incrementally Verifiable MPC
- Hamidreza Khoshakhlagh, Anders Kallesøe, Anders Dalskov
- Uses incremental proofs and an external prover to let auditors verify state updates and committee rotations in long-running MPC.
- <https://eprint.iacr.org/2026/2721>
